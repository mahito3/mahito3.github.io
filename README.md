# IT Passport Drill

ITパスポート試験対策の無料学習アプリです。

## 主な機能

- 全830問（オリジナル730問＋令和6〜8年度 公式過去問300問）
- - カテゴリ別演習・ミニ試験・計算問題特訓モード
  - - 略語チートシート（157用語、ねこ語で解説）
    - - 検索でヒットしない用語はAI先生に質問可能
      - - 正答率に応じてねこの反応が変化する結果画面
        - - バッジ機能（正解数に応じて称号を獲得）
         
          - ## 使い方
         
          - `index.html` を開くだけで動作します（サーバー不要のシングルファイルアプリ）。
         
          - ## 対応シラバス
         
          - IPA ITパスポート試験シラバス Ver.6.5 準拠（令和8年度対応）
