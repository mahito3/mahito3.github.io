AI🤖 AI基礎55語

AI（人工知能）Artificial Intelligence
人間の知的活動（学習・推論・判断・創造）をコンピュータで模倣・拡張する技術の総称にゃ。「弱いAI（特定タスク専用）」と「強いAI（AGI）」に分類され、現在のAIはすべて弱いAIにゃ。
生成AIGenerative AI
文章・画像・音楽・動画など新しいコンテンツを自動で「生成」するAIにゃ。ChatGPTやClaudeが文章を、Midjourneyが画像を、Veo3が動画を作れるのが典型例にゃ。従来のAIが「分類・判別」するのに対して、生成AIは「創る」にゃ。
基盤モデルFoundation Model
大量のデータで事前に学習した巨大なAIモデルにゃ。GPT・Claude・Geminiなどがこれにあたるにゃ。一から学習し直さなくても、少しの調整（ファインチューニング）で様々な用途に使えるのが特徴にゃ。
ニューラルネットワークNeural Network
人間の脳の神経細胞（ニューロン）のつながりを模した計算の仕組みにゃ。たくさんの「ノード」が層を作ってつながり、データから特徴を学習するにゃ。ディープラーニングはこれを何層も重ねたものにゃ。
トランスフォーマーTransformer
2017年にGoogleが発表した、現在のLLMの基盤となるAIの構造にゃ。「注意機構（Attention）」という仕組みで文章中の重要な単語に注目しながら処理するにゃ。GPT・Claude・Geminiすべてこの構造が基本にゃ。
自然言語処理NLP（Natural Language Processing）
人間が日常使う言葉（自然言語）をコンピューターが理解・生成する技術にゃ。翻訳・感情分析・文章要約・チャットボットなどがすべてNLPの応用にゃ。LLMはNLPの最先端技術にゃ。
拡散モデルDiffusion Model
ノイズ（砂嵐）から少しずつきれいな画像を生成する技術にゃ。Stable DiffusionやMidjourneyで使われているにゃ。ランダムな点描画に少しずつ輪郭を加えて絵を完成させるイメージにゃ。
強化学習Reinforcement Learning
ゲームのように「行動→結果→報酬・罰」を繰り返してAIが自分で最適な行動を学ぶ手法にゃ。囲碁AIのAlphaGoや、ChatGPTを人間好みの回答にするRLHFでも使われているにゃ。
転移学習Transfer Learning
ある分野で学習したAIの知識を別の分野に流用することにゃ。英語で学習したモデルに少し日本語を追加学習させるイメージにゃ。ゼロから学習するより少ないデータ・時間で高精度が出せるにゃ。
ファインチューニングFine-tuning
大きな基盤モデルを特定の用途向けに調整・追加学習することにゃ。料理の基本を学んだシェフに「うちのお店の味付けを覚えて」と追加訓練するイメージにゃ。医療AI・法律AIなど専門特化に使われるにゃ。
埋め込み（エンベディング）Embedding
単語や文章を数値のリスト（ベクトル）に変換する技術にゃ。「猫」と「ネコ」が似た数値になり、「犬」は少し違う数値になるにゃ。RAGや検索AIの根幹技術で、意味の近さを数値で比較できるにゃ。
ベクトルDBVector Database
埋め込みで変換した数値（ベクトル）を大量に保存して高速に検索できるデータベースにゃ。「似た内容のデータを素早く探す」のが得意で、RAGシステムの記憶装置として使われるにゃ。
コンテキストウィンドウContext Window
AIが一度に読める文章の最大量のことにゃ。「今の会話で参照できる記憶の長さ」のイメージにゃ。GPT-5やGeminiは100万トークン超えで、本一冊以上を一度に読めるにゃ。長いほど複雑な仕事が得意にゃ。
温度パラメーターTemperature
AIの回答のランダム性を調整する設定にゃ。温度を低くすると毎回同じ堅い答えが返り、高くすると毎回違う創造的な答えが返るにゃ。事実確認は低く・アイデア出しは高くするのが定石にゃ。
マルチエージェントMulti-Agent
複数のAIエージェントが役割分担して協力する仕組みにゃ。「調査担当AI・文章作成AI・校正AI」が連携してレポートを完成させるイメージにゃ。一つのAIより複雑なタスクをこなせるにゃ。
機械学習Machine Learning
人間がルールを教えなくても、データからパターンを自動的に学習する手法にゃ。「教師あり学習」「教師なし学習」「強化学習」の3種類が基本にゃ。
ディープラーニングDeep Learning
人間の脳の神経回路を模倣した多層ニューラルネットワークを使う学習技術にゃ。画像認識・音声認識・自然言語処理で爆発的な精度向上をもたらしたにゃ。
LLM（大規模言語モデル）Large Language Model
インターネット上の膨大なテキストで学習した超巨大なAIモデルにゃ。ChatGPT・Claude・Geminiなどがすべてこれ。文章を「次のトークンを予測する」仕組みで生成するにゃ。
弱いAI / 強いAINarrow AI / AGI
「弱いAI」は囲碁・翻訳など特定タスク専用。現在のAIはすべてこれにゃ。「強いAI（AGI）」は人間のように何でもこなせる汎用AIで、まだ実現していないにゃ。
AGI（汎用人工知能）Artificial General Intelligence
特定の作業だけでなく、人間のようにあらゆることができるAI。まだ実現していない次世代の目標にゃ。
ASI（超人工知能）Artificial Super Intelligence
人間を超えるあらゆる能力を持つAI。AGIのさらに先にある概念にゃ。
シンギュラリティTechnological Singularity
AIが人間の知性を超えて、予測不能な変化が起きる転換点のこと。技術的特異点ともいうにゃ。
創発Emergence
水が100℃で突然気体になるように、AIもデータ量・モデルサイズが一定量を超えると突然新能力が開花する現象にゃ。GPT-3→GPT-4で顕著に見られたにゃ。
RAGRetrieval-Augmented Generation
AIが回答する前に外部DBやネットを検索して最新情報を取り込む技術にゃ。試験中に参考書を持ち込める状態にするイメージ。ハルシネーション対策に有効にゃ。
トークンToken
AIが言語を処理する最小単位にゃ。日本語は英語より多く分割されやすい。トークン数が多いほどAPIコストが増えるにゃ。
パラメーターParameter
モデルが学習を通じて調整する数値の総数で、人間の脳細胞の数に例えられるにゃ。多いほど複雑なパターンを学習できるが計算コストも増えるにゃ。
ハルシネーションHallucination
AIが存在しない論文・人物・事実を自信満々に作り上げる現象にゃ。「幻覚」とも呼ばれる。重要な情報は必ず公式サイトや複数ソースで裏取りするにゃ。
LoRALow-Rank Adaptation
巨大なAIモデル全体を再学習せず、薄いアダプター層だけを学習させる省エネ追加学習手法にゃ。費用と時間を大幅に節約できるにゃ。
量子化Quantization
32ビットの数値を8ビットや4ビットに圧縮してモデルを軽量化する技術にゃ。スマホやPCでも大型モデルが動くようになるにゃ。
蒸留Distillation
賢い大きなモデル（教師）の知識を小さなモデル（生徒）に移す技術にゃ。ベテランのノウハウを新人に伝えるイメージにゃ。
スケーリング則Scaling Law
モデルサイズ・データ量・計算量を増やすほど性能が予測可能な形で向上するという法則にゃ。「デカさは正義」という考え方の根拠にゃ。
AIエージェントAI Agent
目標を与えられると自分で計画を立て、外部ツールを呼び出しながらタスクを自律的に実行するAIにゃ。「計画→実行→観察→修正」のサイクルを繰り返すにゃ。
MCPModel Context Protocol
AIエージェントが外部ツール・DB・APIと標準的に連携するためのプロトコルにゃ。USB規格のようなものにゃ。2026年最新トピックにゃ。
マルチモーダルMultimodal
テキスト・画像・音声・動画など複数の種類のデータを同時に扱えるAIにゃ。「この写真の料理のレシピを教えて」のように画像とテキストを組み合わせた指示ができるにゃ。
XAI（説明可能AI）Explainable AI
AIのブラックボックスを開けて「なぜこう判断したか」を人間に見せる技術にゃ。医療・金融・採用など誤判断が命取りになる場面で特に重視されるにゃ。
再現率・適合率・F値Recall / Precision / F-measure
AIの成績表のようなものにゃ。「再現率」は「本当の病気をどれだけ見逃さなかったか」、「適合率」は「病気と判定したうち本当に病気だった割合」、「F値」はその両方のバランスにゃ。見逃し厳禁の医療AIでは再現率が特に重要にゃ。
推論Inference
AIが勉強し終わった後、実際に質問に答える工程にゃ。「学習」が教科書を読む段階だとすると、「推論」はテストで問題を解く段階にゃ。ChatGPTに質問するたびに推論が行われているにゃ。
RLHFReinforcement Learning from Human Feedback
人間が「この回答は良い・悪い」と採点して、AIをしつけていく学習方法にゃ。子どもに「それはダメ、こっちがいい」と教えるイメージにゃ。ChatGPTが礼儀正しい回答をするのはこの訓練のおかげにゃ。
Chain of Thought思考の連鎖
「一歩ずつ順番に考えて」とAIに伝えるだけで、急に正解率が上がる魔法の一言にゃ。いきなり答えを出すより、途中の計算過程を書かせた方が正確になるにゃ。難しい計算や論理問題に特に効くにゃ。
Few-shot / One-shot / Zero-shot例示の数
AIに「こういう感じで答えてね」と例を見せる枚数のことにゃ。例を複数見せるのがFew-shot、1枚だけがOne-shot、例なしで解かせるのがZero-shotにゃ。例が多いほどAIが望み通りの形式で答えてくれやすくなるにゃ。
アノテーションAnnotation
AIに学習させるデータに「これは犬」「この感情はポジティブ」などと正解ラベルを貼る作業にゃ。教科書に答えを書き込む作業と同じにゃ。AIの賢さはこのラベルの質と量に大きく左右されるにゃ。
モデルドリフトModel Drift
時間が経つにつれてAIの回答精度が落ちていく現象にゃ。去年の流行語を知らないまま今年も答え続けるイメージにゃ。定期的なアップデートやRAGとの組み合わせで対策できるにゃ。
過学習Overfitting
特定のデータに合わせすぎて、少し違うデータが来ると急にダメになる状態にゃ。過去問を全部丸暗記したら本番で問題の言い回しが変わっただけで解けなくなった、というイメージにゃ。
バイアスBias
学習データの偏りがAIの判断の偏りになって出てくることにゃ。「男性のデータばかりで学習したAIが女性に不公平な判断をする」などが典型例にゃ。多様なデータで学習させることが対策にゃ。
拡張知能Augmented Intelligence
AIを「人間を置き換えるもの」ではなく「人間の能力を補う道具」として使う考え方にゃ。眼鏡で視力を補うように、AIで判断力・記憶力・情報処理力を底上げするイメージにゃ。
フィジカルAIPhysical AI
画面の中だけでなく、ロボットアームや自動運転車など現実の「体」を持つAIのことにゃ。工場の自動化・手術支援ロボット・配達ドローンなどが代表例にゃ。2026年のAIトレンドの一つにゃ。
バイブコーディングVibe Coding
「なんとなくこんな感じのアプリ作って」とAIに話しかけながら直感的にプログラムを作る新しいスタイルにゃ。コードの知識がなくてもAIと対話しながらアプリが作れる時代になったにゃ。
プロンプトPrompt
AIへの「お願い文」にゃ。同じ質問でも「短く」「箇条書きで」「専門家向けに」と一言添えるだけで返ってくる答えが大きく変わるにゃ。AIをうまく使いこなす第一歩にゃ。
メタプロンプトMeta Prompt
「プロンプトを作るためのプロンプト」にゃ。「〇〇向けの最適なプロンプトを考えて」とAIに頼むことにゃ。上手な指示文の作り方をAI自身に考えさせる技法にゃ。
プロンプトエンジニアPrompt Engineer
AIへの指示文を上手に書くことを専門にする職業にゃ。「どう聞けば求める答えが返ってくるか」を研究・実践するにゃ。AIが普及した時代ならではの新しい仕事にゃ。
CNNConvolutional Neural Network（畳み込みニューラルネットワーク）
画像の特徴を「畳み込み」という処理で捉えるのが得意なニューラルネットワークにゃ。画像認識・画像生成AIの基礎技術にゃ。
RNNRecurrent Neural Network（再帰型ニューラルネットワーク）
過去の情報を覚えながら順番に処理する、時系列データが得意なニューラルネットワークにゃ。Transformer登場前は文章処理でよく使われてたにゃ。
LSTMLong Short-Term Memory
RNNの弱点（昔の情報をすぐ忘れちゃう）を改良した仕組みにゃ。長い文章でも大事な情報を覚えていられるにゃ。
GANGenerative Adversarial Network（敵対的生成ネットワーク）
「偽物を作る側」と「見破る側」の2つのAIを競わせて学習させる、画像生成の代表的な仕組みにゃ。
VAEVariational Autoencoder（変分オートエンコーダ）
データを一度圧縮してから復元する過程で、新しいデータを生成できるようにする仕組みにゃ。拡散モデル登場前の画像生成でよく使われてたにゃ。

RCSRich Communication Services
ショートメール（SMS）の進化版にゃ。既読確認・画像・動画・スタンプ送信などLINEのような機能が使えるにゃ。iPhoneとAndroid間でも使えるようになり、普及が進んでいるにゃ。
ワークスペースWorkspace
作業する場所・環境のこと。SlackやNotionなどでプロジェクト単位の空間にゃ。メンバーやデータをまとめて管理できるにゃ。
クラウドCloud Computing
データやソフトをネット上のサーバーに保存・処理する仕組みにゃ。自分のPCに保存しなくていいから、どこからでもアクセスできるにゃ。GoogleドライブやiCloudが身近な例にゃ。
SaaSSoftware as a Service
ソフトをネット経由でサービスとして使う形態にゃ。インストール不要で、月額料金で使えるにゃ。Google Workspace・Slack・Notionなどが代表例にゃ。
IoTInternet of Things
家電・センサー・車などあらゆる「モノ」がインターネットにつながる仕組みにゃ。スマート家電・スマートウォッチ・スマートシティの基盤技術にゃ。
5G5th Generation Mobile Network
第5世代移動通信システム。4Gより約100倍速く、つながる端末数も大幅に増えたにゃ。自動運転・遠隔手術・AIリアルタイム処理の基盤になるにゃ。
VPNVirtual Private Network
インターネット上に「暗号化されたトンネル」を作って安全に通信する技術にゃ。カフェのWi-Fiでも情報漏洩リスクを下げられるにゃ。テレワーク時の定番セキュリティ対策にゃ。
CookieCookie / サードパーティCookie
Webサイトがブラウザに保存する小さなデータにゃ。ログイン状態の保持や行動追跡に使われるにゃ。第三者（広告会社など）が設置するサードパーティCookieは規制が強まっているにゃ。
ブロックチェーンBlockchain
データを分散して管理し、改ざんをほぼ不可能にする技術にゃ。暗号資産（ビットコイン）やNFT、スマートコントラクトの基盤にゃ。「みんなで監視し合う台帳」イメージにゃ。
メタバースMetaverse
VRやARで作られた仮想空間の世界にゃ。アバターで人と交流したり、仕事・ゲーム・ショッピングができるにゃ。2020年代後半の主要トレンドの一つにゃ。
AR / VR / XRAugmented / Virtual / Extended Reality
AR（拡張現実）は現実にCGを重ねる技術、VR（仮想現実）は完全な仮想空間、XR（拡張現実）はその総称にゃ。Pokémon GOはAR、Meta QuestはVRの代表例にゃ。
CDNContent Delivery Network
世界中にサーバーを分散配置して、ユーザーに近い場所からWebコンテンツを高速配信する仕組みにゃ。動画や画像の読み込みを速くするインフラにゃ。
フィンテックFinTech
金融（Finance）と技術（Technology）を組み合わせた言葉にゃ。PayPay・LINE Pay・スマホ証券など、お金をスマホで扱う技術・サービス全般のことにゃ。
シェアリングエコノミーSharing Economy
個人が持つモノ・スキル・場所を共有してお金を稼ぐ経済の仕組みにゃ。Airbnb（部屋）・Uber（車）・ランサーズ（スキル）などが代表例にゃ。
スマートシティSmart City
IoT・AI・ビッグデータを使って交通・エネルギー・行政を効率化した都市にゃ。信号の最適化、ゴミ収集の自動化、電力の節約などを一括管理するにゃ。
デジタルツインDigital Twin
現実の工場・都市・設備をデジタル空間にそっくり再現したモデルにゃ。シミュレーションして問題を事前に発見したり、AIで最適化するのに使うにゃ。
ビッグデータBig Data
従来のシステムでは処理しきれない巨大なデータの集まりにゃ。SNSの投稿・購買履歴・センサーデータなどを分析してビジネスに活かすにゃ。AIの学習材料にもなるにゃ。
ビーコンBeacon
Bluetooth電波を使って近くのスマホに情報を送る技術にゃ。店舗でクーポンを自動送信したり、来店客数を計測するのに使われるにゃ。屋内GPSとも呼ばれるにゃ。
フィッシング詐欺Phishing
本物そっくりの偽サイトやメールでパスワードやクレカ情報を盗む詐欺にゃ。AIで精巧な文面が量産されており、年々巧妙化しているにゃ。URLをよく確認することが基本の対策にゃ。
ランサムウェアRansomware
PCのデータを暗号化して「お金を払えば解除する」と脅すマルウェアにゃ。病院・自治体・企業が被害を受けた事例が多数あるにゃ。バックアップが最大の防衛策にゃ。
ダークウェブDark Web
通常の検索エンジンでは見つからない、特殊なブラウザ（Tor）でしかアクセスできないWebの領域にゃ。違法取引に使われることもあり、流出した個人情報が売られることもあるにゃ。
エッジコンピューティングEdge Computing
データをクラウドに送らず、現場（エッジ）に近い端末やサーバーで処理する技術にゃ。自動運転や工場IoTなど、遅延が許されない場面で重要にゃ。
OCROptical Character Recognition
紙やスキャン画像に書かれた文字を、コンピューターが読み取れるテキストに変換する技術にゃ。手書きの書類をAIに読み込ませるときの「入口」になるにゃ。スマホで名刺をスキャンすると自動で文字が入力されるのもこれにゃ。
SEOSearch Engine Optimization（検索エンジン最適化）
Googleなどの検索結果でサイトが上位に出るように工夫することにゃ。
BIBusiness Intelligence
会社に蓄積されたデータを分析して、経営判断に活かすための考え方・ツールのことにゃ。
POSPoint Of Sale（販売時点情報管理）
レジで商品を売った瞬間に、いつ・何が・いくつ売れたかを記録するシステムにゃ。コンビニなどで使われてるにゃ。
GPSGlobal Positioning System（全地球測位システム）
人工衛星からの電波で、自分がいる位置を特定する仕組みにゃ。カーナビやスマホの地図アプリに使われてるにゃ。

IT🔐 セキュリティ（IT全般）12語

ゼロトラストZero Trust
「社内ネットワークだから安全」という思い込みをやめて、アクセスのたびに全員を疑って確認する考え方にゃ。会社の入口を通った後も、部屋ごとにIDカードで確認するイメージにゃ。
多要素認証Multi-Factor Authentication
パスワードだけでなく、スマホに届く確認番号・指紋・顔認証など複数の方法で本人確認する仕組みにゃ。パスワードが漏れても2つ目の壁があるから安心にゃ。不正ログイン対策の基本にゃ。
マルウェアMalware
ウイルス・ワーム・ランサムウェアなど、悪意を持って作られたソフトウェアの総称にゃ。「malicious（悪意ある）」＋「software」を合わせた造語にゃ。感染すると情報漏洩や端末の乗っ取りにつながるにゃ。
DDoS攻撃Distributed Denial of Service
大量のアクセスを一斉に送りつけて、サーバーをパンクさせてサービスを止める攻撃にゃ。お店の前に大勢の人を並ばせて、本当のお客さんが入れなくするイメージにゃ。
ゼロデイ攻撃Zero-day Attack
ソフトの脆弱性が見つかってから、修正パッチが配布されるまでの「無防備な期間（0日目）」を狙う攻撃にゃ。対策が間に合わないため特に危険視されるにゃ。
暗号化Encryption
データを第三者に読めない形に変換する技術にゃ。正しい鍵（パスワードなど）を持つ人だけが元に戻して読めるにゃ。通信の盗聴やデータ漏洩からの防御に欠かせないにゃ。
エンドツーエンド暗号化End-to-End Encryption
送信者から受信者までの間、途中のサーバーでも中身が見えないように暗号化する方式にゃ。LINEやWhatsAppのメッセージがこれで守られているにゃ。運営会社すら中身を読めないのが特徴にゃ。
バグバウンティBug Bounty
企業が自社サービスの脆弱性を見つけたハッカーに報奨金を払う制度にゃ。「敵に回すより味方につける」発想で、悪用される前に安全に修正できるにゃ。GoogleやAppleも実施しているにゃ。
インシデントレスポンスIncident Response
サイバー攻撃や情報漏洩が発生したときの緊急対応手順にゃ。「検知→封じ込め→原因調査→復旧→再発防止」の流れで被害を最小限に抑えるにゃ。事前の訓練が重要にゃ。
SOCSecurity Operation Center
24時間365日、サイバー攻撃の兆候を監視する専門チームや部署のことにゃ。企業のセキュリティの「見張り台」で、異常を早期に発見して対応するにゃ。
サンドボックスSandbox
怪しいプログラムを安全に隔離された環境で試しに動かして、悪さをしないか検証する仕組みにゃ。子供が砂場で自由に遊べるように、本番環境に影響を与えず安全に試せるにゃ。
CVECommon Vulnerabilities and Exposures
世界共通で使われるソフトウェアの脆弱性の識別番号にゃ。「このソフトのCVE-2026-〇〇番の脆弱性が危険」のように、脆弱性情報を世界中で統一して管理するための仕組みにゃ。
